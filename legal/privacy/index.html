개인정보처리방침

시행일 2026-09-10 · Phase A(제휴 픽 단계)

1. 수집하는 정보

이 웹사이트는 회원가입, 로그인, 결제, 주문 기능을 제공하지 않으며 이름·연락처·주소 등 개인정보를 입력받지 않아요.

2. 자동 수집

페이지 조회와 링크 클릭 통계를 익명으로 집계할 수 있어요(측정 도구가 설정된 경우에만). 외부 링크 클릭 시 유입 경로 파라미터(예: 어떤 영상에서 왔는지)를 브라우저 세션 저장소에 잠시 보관하고 서버로 개인 식별 정보를 보내지 않아요.

3. 외부 서비스

제시카 픽은 쿠팡으로 이동해요. 쿠팡에서의 개인정보 처리는 쿠팡의 개인정보처리방침을 따라요. 글꼴은 Google Fonts에서 불러와요.

4. 직접 판매(제시카 스토어) 오픈 시

회원·주문·배송 정보를 처리하게 되면 이 방침을 개정하고 개인정보보호책임자, 보유 기간, 위탁 업체를 명시할 거예요.

5. 문의

문의 창구는 직접 판매 오픈 시 표시돼요. 현재는 각 소셜 채널 DM으로 문의해 주세요.
